# RE-001 v0.5 — Change-Centered Workbench Reference Experience

Status: PROPOSED FOR REVIEW, not accepted. UO-001 remains locked. The prior four-destination reference contract is retained until explicit supersession approval.

## Mission
An application-facing AI engineer can investigate an execution decision, propose a bounded strategy change, evaluate matched cases, inspect regressions, and control a simulated exact-revision activation/restoration. North star: modeled cost per verified automated outcome, constrained by quality, safety, and reliability.

## Design hypothesis
Top-level Attention | Workbench | History. Workbench modes: Inspect | Design change | Compare | Release. Persistent case/step/revision context. Change proposal is the organizing concept. Read-only graph is a projection and evidence selector, never policy source of truth.

## Scope
Six-step service-desk workflow; existing deterministic 100-case fixtures; C1 and C2; selected-case evidence; contract gates; local activation, verification scenarios and restoration; Next.js/React reference UX.

## Explicit deferrals
Arbitrary graph authoring, general workflow imports, live providers, autonomous optimization, distributed services, enterprise approval, multi-environment promotion, production deployment.

## Evidence limitations
The existing fixture engine does not yet have general typed rule execution, runtime/reference label separation, per-step attempts/cost line items, or independent post-release execution batches. Do not imply otherwise. Edited unsupported rules remain inconclusive. Remove illustrative step cost shares rather than displaying them as measured.

## Acceptance for reference UX
Attention -> Inspect -> Design -> Compare -> Release works with persistent case/step; C1 is blocked, C2 eligible by existing engine; editing invalidates evidence; activation/restoration requires confirmation; history remains visible. This is UX review, not full functional acceptance.

## Next separate functional slice
Introduce runtime-observed classifications, typed ordered policy rules, attempts and line-item cost attribution, general contract-derived eligibility, and tests for case-to-decision-to-attempt evidence.
